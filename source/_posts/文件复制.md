# Java IO 流文件复制

字符缓冲流仅用于纯文本复制，字节缓冲流万能适配全类型文件。

## 一、IO 流基础概念

### 字符流（Reader/Writer）
以字符为单位读写，仅支持 txt、md 等纯文本文件。

### 字节流（InputStream/OutputStream）
以原始字节为单位读写，万能兼容任意格式文件。

## 二、字符缓冲流实现文本文件复制

```java
import java.io.*;

try (BufferedReader br = new BufferedReader(new FileReader("source.md"));
     BufferedWriter bw = new BufferedWriter(new FileWriter("copy.md"))) {
    String line;
    while ((line = br.readLine()) != null) {
        bw.write(line);
        bw.newLine();
    }
} catch (IOException e) {
    e.printStackTrace();
}
```

## 三、字节缓冲流实现任意文件复制

```java
try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("demo.jpg"));
     BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("copy.jpg"))) {
    byte[] buffer = new byte[1024];
    int len;
    while ((len = bis.read(buffer)) != -1) {
        bos.write(buffer, 0, len);
    }
    bos.flush();
} catch (IOException e) {
    e.printStackTrace();
}
```
