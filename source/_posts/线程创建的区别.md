# 继承Thread类与实现Runnable接口创建线程的区别

## 一、两种方式代码示例

### 1. 继承Thread子类方式
```java
class MyThread extends Thread{
    @Override
    public void run() {
        System.out.println("线程任务执行");
    }
}
public class Test{
    public static void main(String[] args) {
        MyThread t = new MyThread();
        t.start();
    }
}
```

### 2. 实现Runnable接口
```java
class MyRunnable implements Runnable{
    @Override
    public void run() {
        System.out.println("Runnable线程任务");
    }
}
public class Test{
    public static void main(String[] args) {
        MyRunnable run = new MyRunnable();
        Thread t = new Thread(run);
        t.start();
    }
}
```

## 二、核心区别

1. **继承限制**：继承 Thread 后无法再继承其他类；实现 Runnable 可以多实现
2. **资源共享**：实现 Runnable 可以多个线程共用同一个任务对象
3. **任务与线程解耦**：Runnable 方式任务和线程分离
4. **适用场景**：优先选择实现 Runnable 接口
